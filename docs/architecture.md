# Architecture

`config/fleet-profile.ini` declares the external full fleet independently of any private server. `config/bundled-sources.json` selects the attributed addon modules. `scripts/import-content.py` reads their immutable Workshop downloads, combines selected common/Build 42 media, namespaces imported Lua files and helper requires, merges MCV names, and omits six reviewed older MCV vehicle definitions. Non-Lua asset paths and upstream sandbox keys remain intact. Every shipped output, original path/hash, version-layer decision and omitted definition is recorded in `docs/imported-content.json`, also shipped under `provenance/`. The importer replaces/removes only its unchanged previously manifested outputs.

`scripts/generate-fleet-catalog.ps1` scans external and integrated source modules, respects that omission manifest, identifies semantic vehicle IDs, excludes disabled-only optional variants, merges distribution facts and generates `OnlyKI5VehicleSpawnLiveryOverhaul_Catalog.lua` plus `ki5-provider-inventory.json`. Current external KI5 definitions win all six overlaps; imported Lua references use the external definitions' canonical spelling. New collisions fail generation. The external profile alone determines require/load-order edges; bundled original IDs are incompatible to prevent duplicate activation.

The Catalog owns vehicle groups, exclusions, rarity and weighted candidate lists. SpawnAliases owns exact replacements (including news vans and trailers); PoliceRegions owns jurisdiction/livery roles. Runtime applies the shared policy late in `OnLoadMapZones` and `OnLoadedMapZones`, after WayMoreCars/VMZ mutation. It wraps audited `addVehicleDebug` inputs and has a final pre-creation guard. SmashedPolice removes bypass aliases. PoliceSpawnRouting corrects coordinate-bearing newly created police vehicles through the same regional authority. PoliceLightbars is a separate inherited multiplayer/server spawn-end policy.

Runtime explicitly requires the integrated VMZ distribution and zone-registration modules before registering final selection callbacks. This restores the order formerly supplied by separate mods. VMZ keeps its original sandbox keys, zone data, distributions and four scene recipes. The importer remaps its former library imports to four internal authored modules; no YAPZLib source or runtime requirement remains. No Vanilla's extracted duplicate IDs feed the guarded authored suppression pass. WayMoreCars is a required external mod.

## Native military world support

- `WorldSupport` owns server/single-player authority checks, small table/angle operations and filling only empty newly created scene containers through native loot APIs.
- `MilitaryZones` registers vehicle zones through `IsoWorld.registerVehiclesZone`, deduplicates callbacks, respects overriding map cells across all lot directories, and retains skinned civilian variants when clearing military source pools. It chains the existing global `reloadLuaFile`, preserving its return values, to merge edits only into explicitly registered map `objects.lua` files before the native loader consumes them. A weak vehicle set gates military parking angles to newly created authoritative vehicles.
- `RoadScene` adapts the original recipes' operations to native `RandomizedWorldBase` vehicle, trailer, personnel, corpse and object APIs. Weighted selection uses the final fleet distribution and validates scripts/towing parts; cardinal transforms place local recipe coordinates in the world.
- `RoadStories` schedules the four recipes from authoritative `LoadChunk` and `OnTick` callbacks. New story selection is restricted to new chunks and eligible roads, sandbox frequency/day bounds and unoccupied loaded footprints. Native chunk-size/square access avoids treating a Java array as a Lua table. Each anchor square stores a versioned plain-data checkpoint under `OnlyKI5VehicleSpawnLiveryOverhaul_RoadStory`. Pending checkpoints can resume on later loads; completed, blocked, failed or partially started scenes never respawn. Processing rotates across at most four candidates every 30 ticks; unloaded/long-deferred entries leave memory while retaining their saved checkpoint.

These are project modules, not an additional library mod. Native placement and personnel behavior may differ from the former library: the native personnel helper places zombies near vehicles, and native towing owns trailer positioning. Exact visual placement, physics, saved-world behavior and multiplayer replication require native acceptance. Functional fixtures execute all four imported recipes and production callbacks with native services replaced by spies. `check-native-world-api.ps1` separately verifies 30 installed-build API signatures without creating a world. Official API references: [IsoWorld](https://projectzomboid.com/modding/zombie/iso/IsoWorld.html) and [RandomizedWorldBase](https://projectzomboid.com/modding/zombie/randomizedWorld/RandomizedWorldBase.html).

All authored runtime filenames, require paths, globals, generated distribution names and modData keys use `OnlyKI5VehicleSpawnLiveryOverhaul` / `only_ki5_overhaul`. Original `Base.*` vehicle IDs and dependency module names are external contracts and must not be renamed. The mod ID is new: do not run the private predecessor alongside it and do not treat it as an automatic save migration.

The package contains authored Lua, attributed addon Lua/scripts/assets/settings/translations, provenance, descriptors, native-gameplay screenshot branding with a generated title layer, and license/credit text. Imported contributions retain their authors' ownership and are excluded from MIT. Base KI5 vehicle packs, damnlib, WayMoreCars and installed game code stay outside Git. YAPZLib is neither copied nor required; it remains compatible for unrelated mods that need it. `scripts/sync-release-metadata.py` synchronizes Workshop text, shipped credits/license/provenance and dependency documentation. Public source inspection and portable checks do not require a game installation.
