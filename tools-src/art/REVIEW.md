The owner required actual in-game footage with ONLY KI5 at the bottom. The replacement uses Erika's 2026-10-01 native regional-police capture from the isolated photo home. Its source file matches native screenshot meel_regional_day_4.png by SHA-256. The full 1920x1080 original, source record and hash are preserved. A 705px square crop shows two complete regional patrol vehicles; no vehicle, pavement, lighting or scene detail was generated or repainted.

The image_gen tool produced only a transparent ONLY KI5 title layer. It is placed at (56, 528), 592x159, near the bottom of the 705px crop. The export verifies unchanged capture pixels above the title. Both the 256px icon and 512px poster/preview were opened at actual export size: the title reads clearly, both cars remain fully visible, and the footage retains the game's native appearance. The previous illustrated covers and their generation records are historical files in archive/.

The final images are opaque PNGs because the installed game's ImageData loader and SteamWorkshopItem preview validator use PNGDecoder; the latter checks 256/512 square PNG previews. This native-format constraint is the exception to the usual opaque-JPG export rule. TinyPNG compression remains pending: its website blocked the unattended browser and no configured official API key was present. Do not claim a compressed-file review or full optimization. Native mod-selector appearance and a new Only KI5 gameplay session remain separate, unverified acceptance gates; this existing native capture is artwork evidence rather than new-mod runtime proof.
